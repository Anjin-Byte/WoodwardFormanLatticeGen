Implementation standards:
- Use strict TypeScript
- Do not use SvelteKit unless there is a concrete reason
- Prefer plain Vite app structure
- Keep frontend styling minimal but intentional
- Keep generated scaffolding small and maintainable
- Separate UI concerns from viewer/runtime concerns
- Add comments only where they clarify non-obvious architecture
- Make scripts ergonomic from the repo root
- Avoid placeholder complexity that is not earning its keep
